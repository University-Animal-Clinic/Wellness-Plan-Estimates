Set a New Admin Password

Type the password you want for the pricing admin portal. This page turns it into a fingerprint right here on your computer. Nothing is sent anywhere. Send Claude only the fingerprint it shows you.

Pick something you will remember but others would not guess. Avoid the clinic name, "admin", or "password". A short phrase with a number works well. Keep it somewhere safe like a password manager. The fingerprint is safe to share; your password is not, so do not send the password itself.
